# Notebooks

- **`demo.ipynb`**: a short tour of the unified API (`geodesic`,
  `transport_cost`, `barycenter`, `analysis`) and its three methods. It covers:
  - graphs and densities, on a 5×5 grid;
  - timings of the three methods;
  - multiple shooting, and the default `segments="auto"`;
  - the admissible means;
  - barycenters and analysis;
  - densities that touch zero, and the fallback to the SOCP;
  - an image example: barycenters of digit glyphs;
  - gradients through `transport_cost`, used for gradient descent on a
    density.

  The outputs are committed, so it reads on GitHub without being run. To run
  it:

  ```
  pip install torch --index-url https://download.pytorch.org/whl/cpu
  pip install -e ".[socp,notebook]"
  jupyter lab notebooks/demo.ipynb
  ```

  The cells are generated by `build_demo.py`, so edit them there and rebuild
  with fresh outputs (about five minutes):

  ```
  python notebooks/build_demo.py notebooks/demo.ipynb --execute
  ```
